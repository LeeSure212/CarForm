# CarForm

> **语言：中文**  
> windows系统的无边框显示器，为了方便前端显示

---

## 项目介绍
CarForm 是一个基于 Windows 系统的无边框显示程序，旨在为前端的展示提供便捷的解决方案。该项目完全使用 C# 编写，适合用于开发需要无边框界面的窗口应用。

无边框窗口适用于：
- 自定义展示界面
- 信息展厅或广告牌
- 简洁、全屏的用户界面设计

---

## 功能
- **无边框窗口**：
  - 移除了默认的 Windows 标题栏和边框。
- **前端展示优化**：
  - 专为显示内容而优化，提供良好的视觉效果。
- **高可定制性**：
  - 用户可以根据需求定制界面和交互逻辑。

---

## 使用方法
### 环境要求
- 操作系统：Windows
- 开发环境：Visual Studio 2022 或更高版本
- 依赖：
  1. .NET Framework 或 .NET Core SDK（适用于 C#）
  2. 基础开发库（可根据项目具体需要进行扩展）

### 配置步骤
1. 克隆项目到本地：
   ```bash
   git clone https://github.com/LeeSure212/CarForm.git
   ```
2. 打开 Visual Studio，加载 `CarForm.sln` 解决方案文件。
3. 配置项目依赖并构建。
4. 运行项目，观察无边框窗口效果。
